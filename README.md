# MealGlimpse

A macro tracker that runs as an installable web app. Log meals, save the ones you eat often, and track
calories, protein, carbs, fats and added sugar against daily goals.

Live at https://www.mealglimpse.com (formerly TrackMacros)

## Stack

- React, TypeScript and Vite
- Tailwind CSS for styling, with light and dark themes defined in `src/index.css`
- Dexie (IndexedDB) for on-device storage; meals and goals never leave the device
- `vite-plugin-pwa` for install and offline support

## Free AI logging service

People without their own Gemini key get a small daily allowance of AI logs through a Supabase
edge function (`supabase/functions/estimate`). It holds the Gemini key as a secret, enforces a
per-device and per-address daily limit and a daily and monthly spending budget, and stores only
counters (`supabase/migrations`). The app finds it through the `VITE_AI_PROXY_URL` build variable;
without that variable the app asks for the user's own key instead.

Settings are edge function secrets, all optional except the key: `GEMINI_API_KEY`, `GEMINI_MODELS`,
`DEVICE_DAILY_LIMIT` (5), `IP_DAILY_LIMIT` (20), `DAILY_BUDGET_USD` (0.4), `MONTHLY_BUDGET_USD` (10).

## Food library

`src/data/foods.json` is generated by `scripts/build-food-library.mjs` from the lists in `scripts/`,
using USDA FoodData Central and Open Food Facts. Indian dishes come from the Indian Nutrient Databank
(INDB): `scripts/extract-indb.py` reads INDB's spreadsheet and the dish list in `scripts/food-spec-indb.tsv`
and writes `scripts/indb-foods.json`, which the build script merges in. Deep-fried dishes are left out because
INDB counts all the frying oil.

## Layout

- `src/db.ts`: database tables and all write operations
- `src/hooks.ts`: live queries, the current day, and the theme preference
- `src/lib/`: date and macro helpers, with tests
- `src/components/`: shared UI (summary ring, week strip, sheets, forms, navigation)
- `src/screens/`: Today, Trends, Meals and Profile
